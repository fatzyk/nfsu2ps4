# NFSU2 PS4 source

This directory contains the PS4 port. See the [installation instructions](../README.md#download-and-install) or the [optional build guide](../BUILDING.md).

The port builds on [antoxa2584x/nfsu2-sw](https://github.com/antoxa2584x/nfsu2-sw) and vendors [xboxrecomp](xboxrecomp/README.md). See the upstream project for Nintendo Switch builds.
